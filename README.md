# StockAI - AI-Powered Stock Price Prediction

A full-stack web application that uses LSTM (Long Short-Term Memory) deep learning neural networks to predict stock prices. Built with **Next.js** (frontend) and **Python FastAPI** (backend) with TensorFlow.

## Features

- **LSTM Neural Network**: Deep learning model with 128→64→32→1 architecture
- **16 Technical Indicators**: Moving Averages, RSI, MACD, Bollinger Bands, and more
- **Interactive Charts**: Beautiful Recharts visualizations with historical + predicted data
- **Real-time Data**: Yahoo Finance API integration for live stock data
- **Company Info**: Detailed stock information including market cap, P/E ratio, sector
- **Dark Cyberpunk UI**: Glass-morphism design with gradient accents
- **Model Metrics**: MAE, RMSE, MAPE accuracy indicators
- **Confidence Bounds**: Upper/lower prediction bounds with uncertainty visualization

## Local Development

### Backend Setup

```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Backend runs on `http://localhost:8000`

### Frontend Setup

```bash
npm install
npm run dev
```

Frontend runs on `http://localhost:3000`

Set the API URL:
```bash
# .env.local
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## Deployment

### Frontend (Vercel)

1. Push to GitHub
2. Import project on [Vercel](https://vercel.com)
3. Set environment variable: `NEXT_PUBLIC_API_URL` = your Render backend URL
4. Deploy

### Backend (Render)

1. Push to GitHub
2. Create a new Web Service on [Render](https://render.com)
3. Select the `backend/` directory as root
4. Build command: `pip install -r requirements.txt`
5. Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
6. Deploy

## How It Works

1. **Data Collection**: Fetches historical stock data via Yahoo Finance
2. **Feature Engineering**: Calculates 16 technical indicators
3. **Data Preprocessing**: MinMaxScaler normalization, 60-day sequence windows
4. **Model Training**: LSTM neural network with early stopping
5. **Prediction**: Generates future price predictions with confidence bounds
6. **Visualization**: Interactive charts showing historical vs predicted prices

## Model Architecture

```
LSTM(128, return_sequences=True) → Dropout(0.2)
LSTM(64, return_sequences=False) → Dropout(0.2)
Dense(32, activation='relu')
Dense(1)
```

- **Optimizer**: Adam
- **Loss**: MSE (Mean Squared Error)
- **Epochs**: 25 with early stopping (patience=5)
- **Sequence Length**: 60 days
